# P1093 [NOIP 2007 普及组] 奖学金

## 题目背景

NOIP2007 普及组 T1

## 题目描述

某小学最近得到了一笔赞助，打算拿出其中一部分为学习成绩优秀的前 $5$ 名学生发奖学金。期末，每个学生都有 $3$ 门课的成绩：语文、数学、英语。先按总分从高到低排序，如果两个同学总分相同，再按语文成绩从高到低排序，如果两个同学总分和语文成绩都相同，那么规定学号小的同学排在前面，这样，每个学生的排序是唯一确定的。

任务：先根据输入的 $3$ 门课的成绩计算总分，然后按上述规则排序，最后按排名顺序输出前五名名学生的学号和总分。

注意，在前 $5$ 名同学中，每个人的奖学金都不相同，因此，你必须严格按上述规则排序。例如，在某个正确答案中，如果前两行的输出数据（每行输出两个数：学号、总分) 是：

```plain
7 279  
5 279
```

这两行数据的含义是：总分最高的两个同学的学号依次是 $7$ 号、$5$ 号。这两名同学的总分都是 $279$ (总分等于输入的语文、数学、英语三科成绩之和) ，但学号为 $7$ 的学生语文成绩更高一些。

如果你的前两名的输出数据是：

```plain
5 279  
7 279
```

则按输出错误处理，不能得分。

## 输入格式

共 $n+1$ 行。

第 $1$ 行为一个正整数 $5\le n \le 300$，表示该校参加评选的学生人数。

第 $2$ 到 $n+1$ 行，每行有 $3$ 个用空格隔开的数字，每个数字都在 $0$ 到 $100$ 之间。第 $j$ 行的 $3$ 个数字依次表示学号为 $j-1$ 的学生的语文、数学、英语的成绩。每个学生的学号按照输入顺序编号为 $1\sim n$（恰好是输入数据的行号减 $1$）。

保证所给的数据都是正确的，不必检验。

## 输出格式

共 $5$ 行，每行是两个用空格隔开的正整数，依次表示前 $5$ 名学生的学号和总分。

# 排序与容器踩坑笔记（P1093 奖学金）

本次解题暴露了 C++ 中容器操作和自定义排序的三个核心易错点，特此整理，防止再次踩坑。

---

## 🚨 坑一：`vector` 的初始化与越界（直接导致 RE / 乱码）

### ❌ 我的错误写法
```cpp
vector<int> tmp = {num}; // 此时 tmp 的大小只有 1（只有 tmp[0]）
cin >> tmp[1];           // 💥 越界！C++ 不会自动扩容
```

### ✅ 正确做法
C++ 的 `vector` 必须**先分配大小**，才能用 `[]` 下标直接赋值。
```cpp
// 方法1：直接初始化指定大小（推荐，默认填0）
vector<int> tmp(5); 
tmp[0] = num;
tmp[1] = 语文; // 安全

// 方法2：用 push_back 追加（适合不确定大小的情况）
vector<int> tmp;
tmp.push_back(num);
tmp.push_back(语文);
```

> **📝 笔记总结**：`[]` 只能用于**访问已存在**的元素，不能用来“创造”新元素。用 `[]` 赋值前，确认 `size()` 够大。

---

## 🚨 坑二：`sort` 自定义比较函数（决定成败的核心）

### ❌ 我的错误写法
```cpp
bool my_greater(vector<int> x, vector<int> y) {
    if (x[4] > y[4]) return true;
    if (x[4] == y[4] && x[1] > y[1]) return true;
    return x[0] > y[0]; // 💥 学号要求升序（从小到大），写反了！
}
```

### ✅ 正确写法（多关键字排序标准模板）
```cpp
bool cmp(const vector<int>& x, const vector<int>& y) {
    if (x[4] != y[4]) return x[4] > y[4]; // 1. 总分不同，总分大的在前（降序）
    if (x[1] != y[1]) return x[1] > y[1]; // 2. 语文不同，语文大的在前（降序）
    return x[0] < y[0];                   // 3. 学号小的在前（升序）
}
```

### 💡 核心逻辑：严格弱序（Strict Weak Ordering）
`sort` 的比较函数必须保证 **“如果 a 和 b 相等，必须返回 false”**。
用 `!=` 层层递进是最安全的写法，一旦遇到相等，就交给下一个条件判断。千万别在中间写 `==`，容易写漏返回 `false`。

> **📝 笔记总结**：
> 1. 降序用 `>`，升序用 `<`，别搞反。
> 2. 多关键字用 `if (a != b) return a > b;` 层层往下剥。

---

## 🚨 坑三：比较函数的参数传递（性能杀手）

### ❌ 我的错误写法
```cpp
bool my_greater(vector<int> x, vector<int> y) 
```
**值传递**。每一次比较，都会把两个 `vector` 完整拷贝一遍。如果数组长、数据量大（比如上万个元素），`sort` 的过程中会拷贝几百万次，直接 TLE（超时）。

### ✅ 正确写法
```cpp
bool cmp(const vector<int>& x, const vector<int>& y)
```
**常引用传递**。加 `&` 避免拷贝，加 `const` 防止在比较函数里手滑修改了原数据。

> **📝 笔记总结**：自定义排序函数，参数一律写成 `const T&`。

---

## 🌟 进阶建议：别用二维数组存结构体

用 `vector<vector<int>>` 存学生信息，要死记 `tmp[0]` 是学号，`tmp[1]` 是语文，非常容易乱。遇到这种“一个对象有多个属性”的题，**果断用 `struct`**。

### ✅ 结构体终极模板（直接背下来）
```cpp
#include <bits/stdc++.h>
using namespace std;

// 1. 定义结构体
struct Student {
    int id;       // 学号
    int chinese;  // 语文
    int math;
    int english;
    int total;    // 总分
};

// 2. 写比较函数（传常引用）
bool cmp(const Student& a, const Student& b) {
    if (a.total != b.total) return a.total > b.total;       // 总分降序
    if (a.chinese != b.chinese) return a.chinese > b.chinese; // 语文降序
    return a.id < b.id;                                     // 学号升序
}
int main() {
    int n;
    cin >> n;
    vector<Student> stu(n); // 直接开大小为 n 的数组
    
    for (int i = 0; i < n; ++i) {
        stu[i].id = i + 1;  // 学号从 1 开始
        cin >> stu[i].chinese >> stu[i].math >> stu[i].english;
        stu[i].total = stu[i].chinese + stu[i].math + stu[i].english;
    }
    
    sort(stu.begin(), stu.end(), cmp);
    
    for (int i = 0; i < 5; ++i) {
        cout << stu[i].id << ' ' << stu[i].total << '\n';
    }
    return 0;
}
```

### 为什么用结构体好？
1. **见名知意**：`stu[i].total` 比 `tmp[4]` 好懂一万倍，绝不会记错下标。
2. **不怕越界**：定义结构体成员就那几个，不用手动 `resize`。
3. **方便扩展**：下次如果再加个“物理成绩”，直接加个成员变量就行。

---

## 🎯 一句话总回顾

> **容器赋值先查 `size`，防越界；**
> **多关键字排序用 `!=` 层层剥离，升降序别搞反；**
> **比较函数必带 `const &`，防拷贝；**
> **多属性打包用 `struct`，告别魔法下标。**
